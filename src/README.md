# Código fuente del proyecto

El código Python utilizado para desarrollar este proyecto se encuentra integrado en el notebook de Google Colab:

[Actividad_4_ABG.ipynb](../notebooks/Actividad_4_ABG.ipynb)

El notebook contiene la configuración del entorno, la descarga y preparación del dataset, la implementación de los tres modelos preentrenados, el cálculo de métricas, la medición de latencia y la generación de tablas y gráficos.

Se decidió mantener el código en un único notebook para facilitar su ejecución y evitar duplicar procedimientos en archivos independientes.

Para reproducir el experimento, se deben seguir las instrucciones documentadas en el README principal del repositorio.
